FAQ

下载前，先了解这些。

需要安装 .NET 或者联网才能用吗？

不需要。发布的是 Windows x64 自包含便携版，下载 EXE 双击即可运行，不装 .NET 运行时。只有执行网络检测时才需要联网，局域网协同在内网即可工作。

检测结果会上传吗？

不会。所有检测都在本机完成，结果默认保存在本机，不上传报告，也不含遥测。局域网功能只对你确认过的已配对设备开放。

怎么更新到新版本？

应用会自动检查新版本，在左下角弹出提示。点“立即重启更新”会直接升到最新版本，下载到应用所在目录，替换完成后自动删除旧版本并重新启动，不需要手动下载。

多台设备协同需要什么条件？

设备处于同一局域网，互相配对（配对需双方确认），并升级到相同版本。发现使用 UDP 45678，传输使用 TCP 45679，键鼠低延迟输入使用 UDP 45679；若被防火墙拦截，请允许 Captain Net 访问本地网络。
