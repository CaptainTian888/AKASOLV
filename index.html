FAQ

下载前，先了解这些。

需要安装 .NET 或者联网才能用吗？

不需要。发布的是 Windows x64 自包含便携版，下载 EXE 双击即可运行，不装 .NET 运行时。只有执行网络检测时才需要联网，局域网协同在内网即可工作。

检测结果会上传吗？

不会。所有检测都在本机完成，结果默认保存在本机，不上传报告，也不含遥测。局域网功能只对你确认过的已配对设备开放。

怎么更新到新版本？

应用会自动检查新版本，在左下角弹出提示。点“立即重启更新”会直接升到最新版本，下载到应用所在目录，替换完成后自动删除旧版本并重新启动，不需要手动下载。

多台设备协同需要什么条件？

设备处于同一局域网，互相配对（配对需双方确认），并升级到相同版本。发现使用 UDP 45678，协同/文件/聊天使用 TCP 45679，键鼠使用 UDP 45679，屏幕查看和广播使用 TCP 45680；若被防火墙拦截，请允许 Captain Net 访问专用网络。

屏幕广播会自动让别人看到我的桌面吗？

不会。广播发起后，每台接收设备都会单独弹出置顶邀请，必须点击“接受查看”才会开始画面传输；点“拒绝”不会查看。发起者可以随时结束广播，被查看端也能一键取消。

别人可以直接查看或截取我的屏幕吗？

不行。别人发起查看时，你这边会弹出授权框，不同意就连不上。授权框里“同步扬声器声音”和“允许对方控制键鼠”是两个独立勾选，默认都不开——只同意查看的话，对方只能看画面。对方想要控制权得中途再申请一次，由你二次确认。跨设备截图同样需要你当场同意。

只要屏幕正在被查看或广播，你的页面顶部会一直挂着共享提示，写明是否含声音、是否已交出键鼠控制，随时可以一键取消。

为什么我开着声音共享时，听不到其它设备的声音？

这是有意为之，避免回声。声音同步采集的是整台设备的扬声器输出，如果一边播放对方的声音、一边采集再发回去，两台设备就会互相喂声音、越叠越响。所以同一台设备上「共享」和「收听」是互斥的：谁开共享谁出声，其余设备听。关掉共享开关就会恢复接收。

聊天和文件传输是加密的吗？

是。聊天文本和文件正文会在两台设备之间协商出会话密钥后加密传输（ECDH 协商 + AES-GCM 加密），密钥只存在内存里，不落盘、不经过任何服务器，同一网络里的其他人抓包只能拿到密文。

需要说明的是：密钥协商没有和设备身份做绑定校验，所以它能防住「被偷看」，但挡不住能改写流量的主动中间人。建议仍然只在可信网络中使用局域网协同功能。

聊天记录和发送的文件会上传到云端吗？

不会。聊天记录、备注名和传输历史只保存到各自设备的本地 Captain Net 数据目录；聊天和文件只在已配对设备之间传输，不经过 Captain Net 云端。

文件夹里的 EXE、压缩包等格式会被改坏吗？

完整传输后会按原目录、原文件名和原扩展名还原。传输中使用隐藏临时分片目录，接收完成并校验长度后才生成正式文件名，因此不会把 .part 当成最终文件。

为什么打开某些应用时，鼠标无法跨设备控制？

因为这些窗口的输入权限高于 Captain Net，Windows 会直接拦掉外部程序送进去的键鼠事件。常见的是三种情况：

  • 以管理员身份运行的程序——任务管理器、注册表编辑器、提权安装程序等。Windows 不允许普通权限的进程向更高权限的窗口发送输入。这一种可以解决：把两台设备上的 Captain Net 都改成以管理员身份运行。
  • 系统安全桌面——UAC 提权弹窗、Ctrl+Alt+Del、锁屏和登录界面。这块运行在独立桌面上，任何第三方程序都无法在其中注入输入，属于系统设计，只能用那台设备自己的键鼠操作。
  • 游戏与带反作弊的程序——它们直接读取鼠标的原始输入数据，而不是看光标位置，反作弊模块还会主动过滤掉带「注入」标记的合成事件。

键盘受同样的限制。如果只是某一个窗口点不动，先确认它是不是以管理员身份启动的。
